🚀 Out-of-the-Box Quick StartSetting up your Robot-i SO-101 on a brand-new Windows PC or Linux / Raspberry Pi machine takes less than 5 minutes—no manual Python or Conda setup required.Step 1: Download the SoftwareClone this repository (or download and extract the ZIP):git clone https://github.com/FATHEY12352/robot-i.git
cd robot-i/v4
Step 2: Launch SO-101 Studio V4 (1-Click Bootstrap)On Windows: Double-click start_v4.bat inside the v4 folder.On Linux / Raspberry Pi:chmod +x start_v4.sh
./start_v4.sh
What happens automatically: The launcher creates an isolated Python virtual environment (v4/.venv), detects your NVIDIA GPU / CUDA or CPU architecture, and opens the SO-101 Studio V4 graphical interface.Step 3: Follow the 5-Tab Workflow Inside the AppEnvironment & Health Check: Click "Install / Repair Full Robotics Environment" on first run to automatically provision PyTorch and LeRobot.Hardware & Dual-Cam Wizard: Choose Guided Auto-Discovery (plug in Follower, Leader, Top Camera, and Wrist Camera one by one) and verify both live camera feeds side-by-side.Record Demonstrations: Enter your task name (e.g., "Pick and place"), set the number of episodes (recommended: 30–50), and demonstrate the task using the Leader arm.Train Your AI Policy (ACT):Local GPU Training: Train directly on your workstation with TF32 acceleration enabled.Cloud GPU Export: Click "Prepare & Compress Dataset for Cloud GPU" to generate a ready-to-upload .zip package for remote RTX 4090 / A100 training, then import the trained checkpoint back in one click.Autonomous Rollout: Select your trained model and click "Start Autonomous Robot" to watch your SO-101 execute the task independently. Press Ctrl + C at any time to safely return the arm to its home pose.📂 Repository StructureFolderDescriptionv4/Current Flagship Release — SO-101 Studio V4 (GUI App, 1-Click Bootstrappers, Hardware Wizard, Cloud Packager & Docs)V3/Optimized CLI pipeline with TF32 ACT training configurations and 60 Hz rollout benchmarksV2/Core LeRobot v0.7.0+ integration, dual-camera calibration, and initial policy inference scriptsV1/ & V1 Amazing Hand/Early mechanical prototypes, kinematic studies, and custom end-effector R&D🛠️ Safety & Troubleshooting TipsEmergency Stop & Safe Return: During autonomous rollout, pressing Ctrl + C in the active console smoothly interpolates the arm back to its initial startup position before releasing motor torque.USB Port Re-enumeration: If you plug the arm into a different USB port on Windows, simply open Tab 2 (Hardware Wizard) in Studio V4 and click Scan Ports to update your profile in seconds.Magnet & Encoder Alignment (Leader Arm): If using magnetic rotary encoders (AS5600), maintain an air gap of 1.5 mm – 2.0 mm between the diametrically magnetized magnet and the sensor IC for optimal signal strength.🤝 Built by Robot-iFor hardware inquiries, custom gripper designs, or enterprise/lab deployments, open an issue in this repository or contact our engineering team.
