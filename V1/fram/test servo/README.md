# دليل توصيل وتشغيل جهاز فحص السيرفوهات (Servo Tester)
### المكونات: Arduino Pro Mini (ATmega328P 16MHz) + PCA9685 + شاشة OLED SSD1306 + إنكودر HW-040

---

## 1. مخطط التوصيلات الكامل (Wiring Guide)

### أ. مبرمجة WCH-Link مع Arduino Pro Mini
> [!IMPORTANT]
> بما أن المبرمجة ترفع الكود عبر منفذ السيريال (UART)، تأكد من توصيل خطوط البيانات بشكل عكسي (TX -> RX و RX -> TX)، وخط الـ DTR لعمل Reset تلقائي أثناء الرفع.

| طرف WCH-Link | طرف Arduino Pro Mini | ملاحظات |
| :--- | :--- | :--- |
| **VCC (5V أو 3.3V)** | **VCC** (أو RAW لو 5V) | تغذية البوردة |
| **GND** | **GND** | أرضي مشترك |
| **TXD** | **RX (Pin 0)** | إرسال المبرمجة إلى استقبال الأردوينو |
| **RXD** | **TX (Pin 1)** | استقبال المبرمجة من إرسال الأردوينو |
| **DTR** | **DTR / GRN / RST** | لعمل ريستارت تلقائي وقت الرفع (لو غير موجود اضغط زر Reset يدوياً عند بدء الرفع) |

---

### ب. خطوط الـ I2C (مشتركة بين PCA9685 وشاشة الـ OLED)
كلا الجهازين يعملان ببروتوكول I2C ويتصلان بالتوازي على نفس الأرجل:

| الطرف المشترك | طرف Arduino Pro Mini |
| :--- | :--- |
| **SDA** (في الشاشة والـ PCA9685) | **A4** |
| **SCL** (في الشاشة والـ PCA9685) | **A5** |
| **VCC** | **VCC (5V)** |
| **GND** | **GND** |

---

### ج. حساس الـ Rotary Encoder (موديل HW-040)
| طرف HW-040 | طرف Arduino Pro Mini | وظيفة الطرف |
| :--- | :--- | :--- |
| **GND** | **GND** | الأرضي |
| **+ (VCC)** | **VCC (5V أو 3.3V)** | التغذية |
| **CLK** | **D2** | نبضة الدوران (Interrupt INT0) |
| **DT** | **D3** | نبضة تحديد الاتجاه (Pin D3) |
| **SW** | **D4** | زر ضغطة البكرة للتبديل بين القنوات |

---

## 2. وظائف النظام وكيف يعمل؟

1. **إلغاء القناة رقم 0 تماماً**:
   - تم استبعاد القناة 0 نهائياً من الكود البرمجي ومن واجهة التحكم GUI لأنها غير مستخدمة أو معطلة لديك.
   - القنوات المتاحة للتحكم هي من **1 إلى 15**.

2. **عرض الشاشة (OLED Display)**:
   - في البداية تعرض الشاشة:
     ```text
     SERVO TESTER READY
     ------------------
     CH : 1
     ANG: 90°
     ```
   - عند تحريك أي قناة أو تغييرها، يتم تحديث رقم القناة والزاوية الحالية فوراً.

3. **التحكم بالـ Rotary Encoder (HW-040)**:
   - **الضغط على زر البكرة (SW Click)**: ينتقل تلقائياً للسيرفو التالي:
     `CH 1 -> CH 2 -> CH 3 -> ... -> CH 15 -> CH 1`
   - **تدوير البكرة (Rotation)**:
     - لفة يمين: تزيد الزاوية بنعومة نحو 180°.
     - لفة شمال: تنقص الزاوية بنعومة نحو 0°.

4. **حركة ناعمة ومحمية (Smooth Movement)**:
   - الكود مبرمج ليعمل بنعومة وسلاسة عبر خطوات محسوبة زمنياً في الخلفية لحماية تروس السيرفوهات من الصدمات والاهتزازات المفاجئة.

5. **المزامنة مع واجهة الكمبيوتر (Python GUI)**:
   - يمكنك تشغيل الواجهة:
     ```powershell
     python "d:\projekt\ARM\fram\test servo\gui_servo_controller.py"
     ```
   - عند الضغط على البكرة أو لفها، سيتم تحديث القناة ومؤشر الزاوية في برنامج الكمبيوتر فوراً وتلقائياً.

---

## 3. طريقة الرفع عبر PlatformIO

تم ضبط ملف `platformio.ini` للـ Pro Mini (`pro16MHzatmega328`):
```powershell
pio run -t upload
```
*(لو المبرمجة معندهاش خط DTR، اضغط ضغطة سريعة على زر Reset في الأردوينو أول ما تشوف كلمة `Uploading` في الشاشة).*
